# UnoCSS Starter

Kirby Panel plugin starter preconfigured with [UnoCSS](https://unocss.dev/) and `presetWind3` (Tailwind v3-compatible utilities). See the [UnoCSS guide](https://kirbyup.getkirby.com/guide/unocss) for setup details and the rationale behind the bundled `prefix` and `preflight: false` defaults.

## Scripts

- `pnpm dev` – Start the dev server with HMR
- `pnpm build` – Build for production
- `pnpm lint` – Lint the source
- `pnpm lint:fix` – Lint and auto-fix
