# ESLint Starter

Kirby Panel plugin starter preconfigured with ESLint and [`@antfu/eslint-config`](https://github.com/antfu/eslint-config).

## Scripts

- `pnpm dev` – Start the dev server with HMR
- `pnpm build` – Build for production
- `pnpm lint` – Lint the source
- `pnpm lint:fix` – Lint and auto-fix
